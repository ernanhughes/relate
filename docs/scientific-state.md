### Option B result retained

Registered question:

> Does a frozen code representation that we did not train materially underexpose an objectively measurable compound structural relation under its default geometry?

Frozen setting:

```text
dataset: CodeSearchNet Python
representation: microsoft/codebert-base, frozen
train rows: 20,000
validation rows: 4,000
test rows: 4,000
embedding dimensions: 768
```

External AST-derived coordinates:

1. cyclomatic complexity;
2. maximum control nesting depth;
3. distinct call-site count.

Compound relation:

```text
Chebyshev distance over the three robust-scaled coordinates
```

Primary hard-negative results:

| Method | Accuracy |
|---|---:|
| Raw cosine | `0.532458984375` |
| Raw Euclidean | `0.533314453125` |
| Predicted coordinate executor | `0.732851562500` |
| Best-raw gap | `0.199537109375` |

The registered continuation threshold was `0.10`, so the recorded decision was:

```text
REAL_PREMISE_SUPPORTED
```

The decisive query-score matrix and final decision were independently recomputed by a separate implementation in the source repository.

### Exact claim retained

> In repository-separated real Python code, independently predicted AST primitive coordinates exposed a frozen three-way structural relation materially better than raw CodeBERT cosine or Euclidean geometry on the preregistered hard-negative test.

### What Option B did not establish

It did not establish:

- superiority over a directly trained compound model;
- superiority over supervised metric learning;
- a general relation-composition algorithm;
- semantic understanding;
- production-quality nearest-neighbour retrieval;
- transfer across models, languages, or domains;
- calibrated support or refusal.

These limitations are essential. The new repository inherits the result only at its original scope.

### Lesson retained

The stronger supervised comparison remains worth answering, but the single-seed shuffled-control rule was not a good gate. A future experiment should use a prospective empirical multi-seed null, a properly justified equivalence test, or a simpler falsification control whose error behaviour is understood before execution.

## Current scientific position

Established:

> Frozen embeddings can contain a bounded, externally measurable relation that raw geometry materially underexposes.

Unanswered:

> Does a modular relation-specific recovery method offer a material advantage over strong supervised methods trained for the same relation with equivalent access?

This unanswered comparison is the main scientific target of the new repository.
